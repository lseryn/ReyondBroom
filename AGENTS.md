# FTEBroom development

This is a standalone FTE-native editor repository. Build with scripts/build-windows.ps1. There is no Qt/CMake application here. Write source comments in English and maintain English documentation first with Russian counterparts. Preserve all upstream notices. Test in disposable installations, never in a user game directory. Verify both complete MAP round-trips and gesture constraints when changing QC. Inspect an actual engine screenshot when changing ImGui rendering. Keep the pinned engine patch and its regression tests together.
