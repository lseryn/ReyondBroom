# Tool icons

Selected SVGs from [Lucide](https://github.com/lucide-icons/lucide), pinned to
`20aef31db93fe4d9f398dbb15b120d99c48eef95`.
The included LICENSE contains the ISC and inherited Feather MIT notices.

`scripts/generate-tool-icons.py` converts these paths to native ImGui line drawing.
Generation requires Python and `svgpathtools`; normal builds and the editor do not.
Icons inherit theme text colors and scale with the buttons.
