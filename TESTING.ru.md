# Проверки FTEBroom

Основной журнал: [TESTING.md](TESTING.md).

## 0.5.0-alpha.1 / задача 0.1 — 20.10.2026

Пройдены: оптимизированная сборка плагина; каталог из 190 действий без пересекающихся сочетаний; native Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z, C, блокировка текстовым полем/диалогом, зарезервированные и неизвестные команды; создание/перемещение/отмена жестов; материалы и UV; Clip; Undo/Redo и полные записи граней после сохранения/загрузки; PK3, loose-ресурсы и WASD. Справочник проверен на реальном снимке движка (`screenshots/actions.png`). Для снимков запускать только один тестовый экземпляр, иначе фоновые окна могут сохранить старый кадр.

Запуск: `scripts/test-actions-windows.ps1 -Bundle <bundle> -Python <python>`. Генерация справочника: `python tests/check-actions.py <test-game-dir> docs/shortcuts.md`. Править каталог нужно в `tests/generate-actions.py`, затем запускать этот генератор.

Ручная проверка физического ввода, потери фокуса Windows, нелатинской раскладки и DPI **ещё не выполнена**. Перед задачей 0.2 пройти [чек-лист 0.1](docs/task-0.1.md). Зарезервированные команды пока не реализованы. Управление колесом и камерой сохранено.
