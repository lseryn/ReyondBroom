# Alpha 40 — ресурсы Quake 1 и интеграция с Arch Linux

- В профиле Quake 1 явно разделены **Base game directory (id1)** и **Mod directory**.
  Ресурсы обеих папок и PAK подключаются вместе; мод имеет приоритет. Палитра может
  наследоваться из базового `pak0.pak`. LibreQuake тоже можно использовать как базу.
- Для новой установки Linux и сброса оформления масштаб по умолчанию — 100%.
  Сохранённый масштаб пользователя не сбрасывается.
- При смене формы курсора сохраняется одна поверхность Wayland. Исправлено
  освобождение памяти изображений курсора; второго курсора ImGui нет.
- Добавлен внешний drag-and-drop WAD через Wayland; путь с пробелами и кириллицей
  проверен. X11 использует тот же обработчик импорта. При сборке WAD копируется
  в рабочую папку компилятора. Импорт изображений в WAD пока остаётся Windows-only.
- В Linux-пакет включены зависимости Q3Map2, лицензии и соответствующие исходники.
  Они загружаются только компилятором, без вмешательства в библиотеки рендера редактора.
  Это устраняет ошибку `libassimp.so.5`; размер архива вырос из-за библиотек и исходников.
- В запуске инструментов добавлен Q1-профиль `qbsp` и выбор по игровому профилю.
  Q3Map2 не разрешается запускать для Quake 1. Полная сборка BSP/VIS/LIGHT по-прежнему
  доступна через **Build / Build...**.
- На Linux заработал менеджер обновлений через Python 3: выбор пакета своей ОС,
  контрольные суммы, установка после закрытия, сохранение настроек и резервная копия.
  Windows-менеджер больше не выбирает релиз, в котором есть только Linux-пакет.

## Проверки

Проверено в изолированном Arch Linux с Weston 15 поверх Xvfb и программным OpenGL
под WSL2. Это не проверка на физическом Arch-компьютере со всеми возможными GPU и
композиторами. Прошли проверки наследования палитры из PAK, приоритета мода,
реального перетаскивания из GTK-приложения, сборки Q1/Q3 и предпросмотра BSP,
буфера обмена, а также установки обновления с сохранением файлов и откатом.

## Что проверить у себя

1. Указать `id1` как базовую игру, мод — отдельно. Открыть карту, проверить текстуры
   обеих папок и приоритет мода. После перезапуска оба пути должны сохраниться.
2. Пересекать границы панелей, растягивать их, переходить в текстовые поля,
   вращать камеру и делать Alt-Tab. Курсор должен возвращаться и не раздваиваться.
3. Перетащить один и несколько WAD из файлового менеджера на сцену или Material,
   включая пути с кириллицей. Применить текстуру и собрать карту: текстура должна
   остаться в BSP.
4. Собрать карты Quake 1 и Quake 3. Проверить BSP/VIS/LIGHT, отсутствие ошибок
   библиотек и подходящий профиль запуска инструментов.
5. Проверить 100% при чистых настройках. Старый пользовательский масштаб должен
   сохраняться; его можно изменить вручную в Preferences.
6. Проверить кнопку **Check for updates**. При следующем Linux-релизе обновление
   должно скачаться и установиться после выхода, сохранив пути, раскладку, масштаб,
   бинды, недавние карты и избранное. Alpha 39 ещё не умеет обновляться на Linux:
   alpha 40 нужно распаковать вручную, сохранив свои настройки.

В alpha 40 опубликован Linux-билд. Последний Windows-билд остаётся alpha 37;
общие изменения исходников доступны в Git.

Проверка сцены: модель игрока из базового PAK отображается при отдельно подключённом моде. Для остальных моделей нужны доступный файл и подходящее описание энтити. В тестовой сцене непрозрачный браш перекрывает сетку; сообщённое просвечивание пока не воспроизведено и не объявляется исправленным.
