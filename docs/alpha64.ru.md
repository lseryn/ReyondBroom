# Alpha 64 — редактирование, точность UV и управление модом

UV теперь следует курсору, учитывает вращение и масштаб текстуры. Зона привязки — восемь экранных пикселей с учетом масштаба интерфейса и UV. При сильном приближении доступны дробные шаги; Ctrl отключает привязку.

Escape во встроенном превью мода открывает меню управления: клавиши, чувствительность мыши, инверсия Y. Apply сохраняет настройки редактора, Continue возвращает к просмотру, Back to editing завершает превью. Симуляция при открытом меню продолжается. Файлы мода не меняются. Встроенное превью по-прежнему доступно только в Windows; Linux использует внешний запуск.

Убраны повторные вычисления неизменившихся превью Brush, Scale/Shear, Sweep и Assemble. Добавлен выбор браша при активных инструментах трансформации, кольца Spin, подсказка положения pivot сетки и перемещение стрелками. Обновление Bezier больше не ограничивается прежним интервалом.

Tools и настройки объединены сверху; кнопки сборки перенесены в верхнюю панель. Файловый менеджер по умолчанию свернут. Сохраненные пользовательские раскладки сохраняются; новую можно получить через Reset panel layout. Добавлены клавиши нумпада, настройки сглаживания/фильтрации, Copy log и отключаемые стадии Run profiles. Исправлены порядок подсветки грани, восстановление модели игрока и завершение превью при выходе.

## Что проверить

1. UV при разных увеличениях, вращениях и масштабах текстуры: направление движения, привязка, мелкая подгонка с Ctrl, Undo/Redo и Escape.
2. Windows: Escape в Free camera и Play mod, переназначение клавиш, Apply, сохранение после перезапуска, возврат к редактированию и закрытие редактора.
3. hotel02: полет, Brush, Face, Rotate, Scale, Shear, Sweep, выбор объектов внутри инструмента и отмена.
4. Bezier — точки и геометрия одновременно; Spin — кольца; Grid Rotate — pivot, стрелки и сброс.
5. Q1 Sculpt на разбитом на браши рельефе с вершинами внутри радиуса; Raise/Lower/Smooth и Undo/Redo.
6. Сборка небольшой закрытой Q1/Q3 карты, BSP/MAP, отключение стадии, Copy log, Stop и ошибка компилятора.
7. Сглаживание вдали, желтая грань при Shift, модель игрока, перекрытие подписей и рамок брашами, фон за BSP.
8. Новая раскладка, Show files / Hide files, нумпад, ПКМ после смены фокуса.

Оптимизации не гарантируют одинаковый FPS на всех картах. Визуальные случаи с пользовательскими шейдерами нужно проверить отдельно. Исправление MAX_MOD_KNOWN из alpha 63 сохранено; старый лог не позволил установить иной новый источник вылета.
