# Файловый браузер и автонавигация — 0.5.0-alpha.12

[English](task-1.5.md) · [Что проверить](checks-1.5.ru.md)

File → Open (Ctrl+O) открывает файловый браузер ImGui. Двойной клик открывает папку; Up поднимает на уровень выше; Drive выбирает диск. Можно ввести путь в Folder и нажать Go. Выдели `.map` и нажми Open. Поддерживаются папки вне редактора, пробелы и кириллица. Для отображения имён в Windows используется установленный Segoe UI; сам шрифт в архив не включён.

Save As (Ctrl+Shift+S) позволяет выбрать папку и имя. Расширение `.map` добавляется автоматически, если оно не указано. Перед заменой существующего файла появляется подтверждение. Save (Ctrl+S) сохраняет текущий файл; для нового безымянного документа открывается браузер. Cancel ничего не меняет. Защита несохранённых изменений при открытии другой карты остаётся.

Движок читает локальную рабочую копию с техническим именем, а интерфейс хранит выбранный полный путь. Пользовательские пути не подставляются в команды движка. При сохранении FTE записывает карту, затем она копируется во временный файл рядом с назначением и атомарно заменяет его. Путь документа и отметка сохранения обновляются только после успеха. Автосохранения остаются в папке autosave редактора.

Ctrl+U плавно, за 150 мс, фокусирует перспективную камеру на выделении без поворота. Дистанция рассчитана по ограничивающей сфере и меньшему углу обзора реального окна. Все 2D-виды центрируются на выделении с сохранением масштаба. Ручное управление камерой прерывает анимацию. Без выделения команда ничего не делает.

View → Move Camera to… задаёт X/Y/Z в пределах ±65536 и перемещает перспективную камеру, сохраняя её углы и центры 2D-видов. Эти команды не меняют карту и историю Undo.

Загрузка point-файлов относится к этапу 20.3. Переход по их точкам пока недоступен до реализации загрузчика.

Этап alpha.11 принят пользователем. Автотесты проверяют внешние пути с кириллицей и пробелами, сохранность оригинала, последующий Save, браши/сущности/патчи после повторной загрузки, ошибку сохранения, навигацию и кнопки браузера, попадание всех восьми углов выделения в вид, анимацию и неизменность карты.
