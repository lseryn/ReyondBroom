# Alpha 56: коллекции префабов

Открой **View → Prefab collections**, выбери MAP и нажми **Add / reload collection**. Именованные группы станут карточками. MAP можно также перетащить из файлового менеджера на эту кнопку. Доступны поиск, размер карточек, сворачивание коллекций и удаление регистрации через правую кнопку на заголовке. Поддерживается навигация внутри PAK/PK3. Исходные файлы не меняются.

Перетащи карточку в 2D/3D-вьюпорт. Вставляются содержимое группы, вложенные группы и энтити. Идентификаторы переназначаются, связи симметрии и связанных групп отключаются, имя верхней группы получает уникальный суффикс. Undo удаляет вставку целиком. Материалы нужно загрузить в текущий профиль. Игровые target/targetname сохраняются: при необходимости разных цепочек активации измени их самостоятельно.

Карточки пока текстовые, без отрисованной миниатюры геометрии и призрака вставки при перетаскивании. Это остаётся в списке различий.

## Что проверить

1. Загрузка нескольких коллекций, фильтр, размеры карточек, сворачивание, удаление регистрации и сохранение списка после перезапуска.
2. Вставка в перспективе и трёх 2D-видах; привязка к сетке, Undo/Redo.
3. Две вставки одного префаба: разные имена, независимое редактирование.
4. Вложенные группы, брашевые и точечные энтити, патчи. Посторонняя геометрия коллекции не вставляется.
5. Сохранение и повторное открытие карты, неизменность исходной коллекции.
6. MAP внутри PAK/PK3, отсутствующие и повреждённые файлы, несовместимый профиль.
