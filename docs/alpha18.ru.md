# Alpha.18: геометрия, сущности и организация карты

[English — основная документация](alpha18.md) · [Полный список проверок](checks-alpha18.ru.md)

В этой версии добавлены рабочие инструменты фаз 8–15 и оставшиеся Move Face и история центра вращения. Интерфейс остаётся на Dear ImGui. Связанные группы, инструменты патчей, Sweep и UV-редактор не разрабатывались. Уже существующие патчи по-прежнему читаются, выделяются, трансформируются и сохраняются.

## Новые инструменты

- **Clip (C):** две/три точки, определение плоскости по поверхности и виду, перетаскивание точек, создание пары протягиванием, двойной клик по грани. Отсекаемая часть полупрозрачная оранжевая. Front/Both/Back выбирает сохраняемую сторону. Невалидный разрез не меняет исходный браш.
- **CSG:** Convex Merge (Ctrl+J), Subtract (Ctrl+K), Hollow (Ctrl+L), Intersect (Ctrl+Shift+K). Толщина Hollow равна сетке; слишком тонкие браши пропускаются. Скрытые/заблокированные объекты исключаются из Subtract.
- **V/E/F:** редактирование вершин, рёбер и граней; выделение рамкой, Ctrl-клик, перемещение, удаление, привязка. Геометрия остаётся выпуклой. Shift-протягивание с поверхности добавляет вершину; Shift+Alt-клик по вершине выполняет слияние. Esc отменяет предпросмотр.
- **Move Face:** Shift+Alt-протягивание грани выделенного целиком браша. В 2D движение идёт в плоскости вида, в 3D — по нормали грани.
- **Scale/Shear:** ручки, рёбра и стороны габаритной рамки, числовые размеры/коэффициенты. Alt масштабирует относительно центра, Shift сохраняет пропорции. Выделенные вершины/рёбра/грани можно передать в Rotate/Scale/Shear.
- **Rotate:** перемещение центра вращения теперь поддерживает Undo/Redo.
- **Brush (B):** точки на поверхностях в перспективе, прямоугольник протягиванием, копирование контура грани двойным кликом, придание толщины через Shift-протягивание. Enter создаёт браш; нужны минимум четыре некомпланарные точки.
- **Примитивы:** коробка, цилиндр и полый цилиндр, конус, UV-сфера, икосаэдр, лестница, арка и заполнение углов арки. Настройки оси, количества сторон, типа окружности и толщины. Многосоставные фигуры можно группировать.
- Масштаб текстур новых поверхностей по умолчанию — **0.5**. При загрузке существующих MAP он повторно не применяется.

## Сущности

Entity → Settings загружает встроенные 53 определения Quake 3 или внешний `.ent`, `.def`, `.fgd`. Поддержаны includes и наследование FGD. Путь сохраняется в `_tb_def`, F6 перечитывает определения. Ошибка нового файла не уничтожает предыдущие определения.

Перетащи точечный класс из браузера на сцену; появится рамка предпросмотра. Двойной клик создаёт сущность в заданной числовой позиции. Для brush entity сначала выдели браши. Контекстное меню сцены также создаёт сущности и переносит браши в существующую сущность.

Инспектор редактирует выбранные сущности либо владельцев выбранных брашей, без выделения — worldspawn. Таблица позволяет менять ширину столбцов. Enter применяет текст и переходит вниз по столбцу, Tab сохраняет ввод и переходит к следующей ячейке. Ctrl+Enter или + New property добавляет свойство. Instantiate defaults on creation включает заполнение значений при создании; для Quake 3 по умолчанию выключено. ПКМ по полю открывает удаление/переименование/сброс. Есть значения по умолчанию и команды existing/missing/all. Флаги меняют нужный бит у каждой сущности, сохраняя остальные. Поддержаны choice и color. Модели используют пути ресурсов и свойства model/frame/skin/modelscale/modelscale_vec/angle/angles/mangle. Отсутствующая модель заменяется рамкой класса.

Связи target/killtarget отображаются стрелками в режимах None/Direct/Transitive/All.

## Группы, слои и экспорт

Map → Groups and visibility: Group/Ungroup/Rename, Hide/Isolate/Show All. Ctrl+G открывает ввод имени. Двойной клик открывает группу, снаружи объекты блокируются. Контекстное меню позволяет объединять группы, добавлять/извлекать объекты и переносить их по слоям.

Map → Layers: активный слой, видимость, блокировка, исключение из экспорта, порядок и контекстное меню. Метаданные сохраняются в обычном MAP. Make Structural возвращает браши в окружающую группу/слой и снимает редактируемые спец-теги.

**File → Export Map…** создаёт отдельный файл для компилятора: раскрывает группы/слои, удаляет `_tb_*`, исключает слои с omit. Имя и состояние открытого документа не меняются. Обычное Save сохраняет организацию карты.

View options управляет классами и тегами, рамками/именами/моделями, режимом текстур/плоской заливки/каркаса, затенением, рёбрами, связями и границами карты. Короткий ПКМ открывает контекстное меню, протягивание ПКМ вращает камеру.

## Ограничения

Это экспериментальная реализация, а не заявление о полном совпадении со всеми мелочами эталона. Инспектор поддерживает Tab, Enter и Ctrl+Enter, но выделение ячеек стрелками ещё не полностью повторяет эталон. Браузер показывает объёмные рамки классов вместо миниатюр моделей. Произвольные выражения моделей из файлов определений не исполняются.

Лимит движка — **64 грани на выпуклый браш**. Icosphere accuracy выше 0 отклоняется: следующий уровень требует 80 граней. Brush по точкам работает в перспективе. Патчи поддерживают текстурный, плоский, затенённый и каркасный режимы. Use fog управляет туманом движка. Слияние вершин сохраняется до конца протягивания, Escape восстанавливает исходную пару. Color picker применяет изменение при завершении редактирования.

Экспорт — Valve 220 + синтаксис патчей Quake 3. Компиляция/запуск карты и фазы 16–20 не входят в эту версию. Подробный список пользовательских проверок приведён отдельно.
