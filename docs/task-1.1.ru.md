## Управление

Команды работают над сценой в режиме Perspective:

| Действие | Результат |
| --- | --- |
| Протягивание ПКМ | Поворот взгляда; наклон ограничен ±89°, крен отсутствует |
| Alt + ПКМ | Орбита вокруг поверхности под курсором; при промахе — вокруг точки в 256 единицах впереди |
| Колесо во время орбиты | Радиус орбиты, минимум 32 единицы |
| Колесо при обычном протягивании ПКМ | Скорость полёта ±5% за щелчок, диапазон 100–10000 |
| Протягивание средней кнопкой | Панорамирование в плоскости камеры |
| Alt + средняя кнопка | Опциональное перемещение вперёд/назад, включается в Preferences |
| WASD | Полёт относительно взгляда, включая вертикальную составляющую |
| Q / X | Вверх/вниз по мировой оси Z |
| Shift / Alt при полёте | Удвоить / уменьшить вдвое скорость |
| Shift + колесо | Зум через поле зрения |
| Ctrl + Alt + Z | Сброс зума к базовому FOV |
| Обычное колесо | По умолчанию сетка; при отключённой legacy-настройке — движение камеры |
| Ctrl + Alt + колесо | Сетка, если не выполняется жест камеры |

Камера не меняет карту и не создаёт записей Undo. При вводе текста, открытом диалоге, жесте редактирования и Ctrl-сочетаниях полёт блокируется. Escape завершает захват мыши. Для WASD не нужно держать кнопку мыши.

В Preferences доступны чувствительность взгляда, панорамирования и колеса, скорость полёта, базовый FOV, инверсия взгляда и колеса, движение к курсору и режим Alt + средняя кнопка. При приближении зумом чувствительность и скорость уменьшаются. Постоянное сохранение общих настроек относится к более позднему этапу.

## Захват мыши и сохранение ракурса

Патч движка включает относительное движение мыши: курсор скрывается при захвате, поворот не должен упираться в край окна, после отпускания курсор возвращается на исходную позицию. Старый csaddon теперь учитывает захват. После возврата из другого меню восстанавливается обычный указатель.

Позиция, углы и зум хранятся отдельно для каждого имени карты в `ftebroom/cameras/*.cam`. Состояние записывается во время работы, перед сменой карты и при закрытии. Открытие карты восстанавливает ракурс; для новой карты используется начальный. Запоздалая стартовая команда больше не сбрасывает положение. MAP и история не затрагиваются. Карты с одинаковым базовым именем используют общую запись камеры.

## Проверки и границы этапа

Сценарий `scripts/test-navigation-windows.ps1` запускает две временные копии движка последовательно: 27 проверок камеры в QC, 10 проверок ввода/захвата в нативном интерфейсе, две проверки восстановления ракурса, сравнение MAP и скриншоты работающего редактора. События мыши в автотестах подаются в обработчик программно; реальные края окна, возврат указателя, смену фокуса ОС и масштаб Windows нужно проверить вручную.

Также повторяются проверки документа, редактирования, жестов, команд, инструментов, истории, сетки, выбора, геометрии, ресурсов проекта и готовых сцен.

Полное управление камерой 2D и фоновая ортографическая сетка остаются задачей 1.2. Создание patches и незавершённые инструменты этим этапом не добавляются.
