# Задача 0.2 — каркас модальных инструментов

Задача 0.1 принята пользователем 20.10.2026. Эта итерация добавляет жизненный цикл режимов и панель инструментов. Геометрические операции всех показанных режимов пока не реализованы.

## Что работает

Default объединяет выбор кликом, создание протягиванием и перемещение выделенного браша. Старые Move/Box убраны; прежнее перемещение невыделенного браша включается через File → Preferences.

B/C/R/Y/T/G/V/E/F/P включают режимы Brush/Clip/Rotate/Sweep/Scale/Shear/Vertex/Edge/Face/Control Point. Повторное нажатие выключает режим. Новый режим заменяет предыдущий и очищает его состояние.

Escape отменяет текущий жест, затем убирает последнюю точку Clip (либо очищает подготовленные точки Brush/состояние ручек), затем выключает пустой режим. В Default он снимает выделение отдельным шагом Undo/Redo. Shift+Escape сразу выключает режим. В диалоге Escape закрывает диалог без воздействия на карту.

У Clip работают Enter, Ctrl+Enter (смена стороны), Delete (последняя точка) и верхняя строка параметров. В Default строка Move objects by перемещает выделенные целые браши на заданные XYZ одним шагом истории; смешанное выделение граней/патчей отвергается до изменения карты. Каждый компонент смещения ограничен ±8192.

TL удерживает текстуру при перемещении. UV Lock пока сохраняет настройку режима; её применение к сложным преобразованиям — последующая задача. Undo/Redo и открытие карты сбрасывают устаревшие предпросмотры.

## Что пока является каркасом

Геометрию редактируют Clip и Default. Brush хранит подготовку точек и отмену, но ещё не строит многогранник. У остальных новых режимов работают только включение/выключение и сброс состояния; интерфейс помечает их как framework. Extrude, entity drop, сложные страницы параметров и View Options будут подключены вместе с соответствующими операциями. Эта сборка не означает полный паритет с TrenchBroom.

## Проверка

1. Создайте браш. C → C: Clip включается и выключается. C → V: Vertex заменяет Clip. Shift+Escape: Default.
2. В Clip поставьте три точки. Escape ×3: 3 → 2 → 1 → 0. Ещё Escape выключает Clip, ещё один снимает выделение. Ctrl+Z возвращает выделение; Ctrl+Y снова снимает, не меняя карту.
3. Проверьте Ctrl+Enter, Delete, применение разреза, Undo/Redo.
4. Начните перемещение, нажмите Escape до отпускания мыши: изменения отменяются. Повторите с Alt-Z.
5. Move objects by: 32/0/0 → Apply → Undo → Redo. Сравните движение текстуры при TL вкл./выкл.
6. Проверьте ввод в полях, Escape в диалогах и прежний способ перетаскивания через Preferences.

Используйте копии карт. Тест состояния ручек синтетический: полноценное редактирование вершин не заявляется. Физический ввод и фокус Windows требуют ручной проверки.
