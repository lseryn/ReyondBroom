# Прогресс реализации — alpha.21

Область работ — фазы **0–20**. Инструменты фаз 16–20 реализованы и проверяются регрессионными тестами; версия остаётся экспериментальной. См. [функции и ограничения](alpha21.ru.md), [ручные проверки](checks-alpha21.ru.md), [результаты тестов](../TESTING.md).

Постоянная основная панель — намеренное отличие по пожеланию пользователя. Предел выпуклого браша — 64 грани. Проверки внешнего компилятора и Blender остаются в ручном списке; автоматические тесты не гарантируют одинаковое поведение на любой карте.
