# Ход реализации — alpha.18

Граница: фазы **0–15**, фазы 16–20 исключены пользователем. Интерфейс остаётся ImGui.

Добавлены инструменты фаз 8–15 и ранние Move Face/история центра вращения: Clip, CSG, вершины/рёбра/грани, Scale/Shear, построение по точкам, примитивы, определения/браузер/свойства/связи сущностей, группы/слои/видимость/теги и экспорт для компилятора. [Инструкция и ограничения](alpha18.ru.md), [полный список проверок](checks-alpha18.ru.md), [автоматические тесты](../TESTING.md).

Наличие инструмента не означает закрытие каждого критерия спецификации: остаются отличия навигации по таблице свойств, миниатюры/выражения моделей. Связанные группы, инструменты патчей, Sweep и UV-редактор не начинались.
