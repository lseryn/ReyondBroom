# Implementation progress — alpha.21

Roadmap scope is phases **0–20**. Phase 16–20 tools are implemented and covered by focused regression tests; the release remains experimental. See [features and limits](alpha21.md), [manual acceptance checks](checks-alpha21.md) and [recorded tests](../TESTING.md).

The permanent main workspace is an intentional user-requested difference from hideable-panel shortcuts. Convex brushes remain limited to 64 faces. External compiler and Blender acceptance require the manual checks; automated tests do not establish identical behavior for every map.
