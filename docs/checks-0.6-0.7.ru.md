# Полный список ручных проверок: этапы 0.6 и 0.7

[English](checks-0.6-0.7.md)

## Подготовка

Распакуй **весь ZIP alpha.7** в новую папку. Закрой другие окна FTEBroom. Запусти **Launch-Checks.cmd**, расположенный рядом с Launch-FTEBroom.cmd. В появившемся списке нажми **1, 2, 3 или 4**. Подожди около 10 секунд: загрузятся тестовая карта и заданное положение камеры.

Все текстуры входят в сборку. Quake 3 и создание patch для этих сцен не нужны. Между сценами закрывай редактор и снова запускай Launch-Checks.cmd. Повторный запуск открывает исходную сцену, если ты специально не сохранил изменения поверх её файла.

Для проверки сохранения используй новое имя, например **qa_result**, не перезаписывай исходные qa-карты. Обычный Launch-FTEBroom.cmd по-прежнему запускает стандартный редактор.

**Что значит «перекрывающиеся браши».** Это два отдельных объекта, которые с данного ракурса находятся один за другим и занимают одно место на экране. Они не обязаны пересекаться в пространстве. В сценах 1 и 2 большой красный бокс находится перед маленьким синим; между ними есть зазор.

## 1. Перспектива: выбрать ближайший объект

В Launch-Checks.cmd нажми **1**. В списке View должно быть **Perspective**.

1. Один раз кликни в центр красного прямоугольника, не протягивая мышь. Должен выделиться только большой красный браш. Маленький синий за ним не должен выбираться «сквозь» красный.
2. Открой вкладку **Material** справа: материал выбранного браша — `ftebroom/qa_red`.
3. Нажми Escape — выделение снимется. Ctrl+Z вернёт выделение, Ctrl+Y снова снимет его.
4. Сдвинь камеру вбок клавишами A/D, при необходимости поверни взгляд с зажатой ПКМ, чтобы увидеть синий браш сбоку от красного. Кликни по открытой части синего браша: теперь он должен нормально выделяться, материал — `ftebroom/qa_blue`.

Это проверка обычного выбора ближайшей поверхности. Перебора всех объектов в глубине здесь ещё нет.

## 2. Вид 2D: выбрать меньший объект

Закрой редактор, снова запусти Launch-Checks.cmd и нажми **2**. View должен показывать **Y (front)**. На экране будет маленький прямоугольник внутри большого. Это те же два браша, но без перспективы; маленький находится за большим.

1. Кликни **внутри маленького прямоугольника**. Должен выделиться только маленький браш. В Material — `ftebroom/qa_blue`.
2. Кликни **внутри большого, но за пределами маленького прямоугольника**. Должен выделиться большой браш. В Material — `ftebroom/qa_red`.
3. Повтори несколько раз. Браши должны только выделяться, не перемещаться и не создаваться.
4. Проверь Ctrl+Z/Ctrl+Y для смены выделения.

Правило 2D выбирает меньшую проекцию грани под курсором, даже если этот объект расположен дальше. В каркасном виде цвет материала может быть не виден — проверяй имя во вкладке Material.

## 3. Готовый patch и точечная сущность

Выбери **3**. Зелёный изогнутый лист — готовый **patch**: поверхность, форма которой задаётся сеткой контрольных точек. Это не объёмный браш. Маленькая проволочная рамка рядом — сущность `info_player_deathmatch`.

1. Кликни в середину зелёной поверхности — patch должен подсветиться. Кликни по другой видимой части той же поверхности — выбранным должен оставаться patch.
2. Один раз кликни по пустоте рядом, без протягивания: новый объект не должен создаться.
3. Выдели patch; проверь Escape, Ctrl+Z и Ctrl+Y: выделение снимается, возвращается и снова снимается.
4. Кликни по маленькой рамке сущности. Она должна подсветиться, а справа появиться **Entity: info_player_deathmatch**.
5. Для сущности тоже проверь Escape, Ctrl+Z и Ctrl+Y.
6. Переключи View на **Y (front)** или **Z (top)** и обратно на **Perspective**. Панель должна оставаться рабочей, сцена не должна измениться.

**Создания patches через интерфейс в этой версии ещё нет.** Самостоятельно создавать зелёный лист не нужно. Редактирование его контрольных точек, перемещение/свойства сущностей и выбор точной поверхности модели сущности в эти этапы не входят. Общий счётчик выделения пока может называть выбранный patch одним brush — превращать его в браш не требуется.

## 4. Clip и основные операции

Выбери **4**. Перед тобой один синий куб.

1. Выдели куб и нажми **C**. Должен включиться Clip; инструмент присутствует на панели.
2. Поставь две разные точки на видимой верхней грани так, чтобы линия проходила через её внутреннюю область. Не ставь обе точки на одном внешнем ребре. Для первого разреза проще провести линию параллельно одному из рёбер куба.
3. Выбери **Keep → Front**, затем **Back**. Часть, которая будет удалена, должна быть полупрозрачной. При смене стороны предпросмотр должен меняться. В **Both sides** остаются обе половины.
4. Проверь **Ctrl+Enter** — переключение оставляемой стороны. Затем **Enter** или Apply — применение. Убедись, что результат совпадает с предпросмотром.
5. Ctrl+Z должен вернуть цельный куб, Ctrl+Y — результат разреза. Повтори с **Both sides**: получатся две отдельно выделяемые половины.
6. Escape сначала убирает точки Clip, затем выходит из инструмента. Отодвинь одну половину: срез должен быть закрытой гранью, не дырой. При перемещении не должно оставаться копии на исходном месте. Отмени перемещение.
7. Верни цельный куб через Undo. Во вкладке Material задай всему кубу **Scale X = 2**, **Scale Y = 4**, **Angle = 30**. Снова разрежь. На исходных наружных поверхностях текстура должна сохранить масштаб и поворот; новая грань среза получает текущий материал со стандартным преобразованием. Undo/Redo должны сохранять этот результат.
8. Попробуй диагональный разрез через внутреннюю область куба. Обе половины должны остаться замкнутыми и выделяемыми.
9. Попробуй линию, которая только касается внешнего ребра, и линию целиком вне куба. Куб не должен измениться; тонкие дубликаты или сломанная геометрия не должны появиться. Недопустимый разрез может быть отклонён.
10. Выдели целую половину и нажми **Delete**, когда курсор в сцене и ни одно текстовое поле не редактируется. Должна удалиться только она. Ctrl+Z вернёт её, Ctrl+Y снова удалит.
11. Перемести целый браш обычным протягиванием: меняются X/Y, высота остаётся прежней. При зажатом Alt должна меняться только высота. Escape во время протягивания отменяет действие.
12. Протяни мышь по пустому месту, создавая браш. Начальная высота должна равняться одному шагу сетки. Undo/Redo удаляют и возвращают созданный браш.
13. Измени сетку колесом и через список Grid. Проверь линии сетки на поверхностях. В настройках по умолчанию колесо меняет размер сетки.
14. Сохрани карту как **qa_result**, открой другую поставляемую qa-карту и снова открой qa_result. Проверь геометрию разрезов, материалы и масштабы. Постоянная панель должна оставаться видимой после каждой загрузки.
15. В завершение открой **копию** одной своей рабочей карты с проектом Quake 3. Проверь загрузку текстур, выделение/перемещение/Clip простого браша, Undo/Redo, сохранение под новым именем и повторное открытие.

## Что вручную повторять не нужно

26 геометрических и 25 проверок выбора покрывают порядок попаданий, скрытые/заблокированные узлы, приоритет ручек, вершины/рёбра/грани, оболочки, объём, недопустимые браши, UV и 64 грани. До/после операций чтения сравнивается экспорт MAP. Полных пользовательских инструментов для части этих API ещё нет.

Для отчёта достаточно написать по каждой сцене **OK** либо указать первый неработающий шаг: номер сцены и пункта, ожидание и фактический результат, масштаб Windows. При визуальной ошибке поможет скриншот или короткое видео. Если ошибка только на своей карте — небольшой пример, на котором она повторяется.
