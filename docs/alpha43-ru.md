# FTEBroom alpha 43

Основная документация и полный список проверок: [English](alpha43.md).

Добавлены операции внутри PK3, удаление файлов с резервной копией, открытие текстовых файлов двойным кликом и защита несохранённого текста. После изменения подключённых ресурсов используйте Reload engine resources. Удаление файлов не связано с Undo карты: обычные файлы перемещаются в `.ftebroom-trash`, архивы получают копию `.bak`.

Миниатюры декодируются в фоне; исправлено изменение высоты строк при прокрутке. В FTE Custom game появился выбор defaultwall из исходников, мода либо оригинального студийного шейдера, приблизительно имитирующего редактор Unity. Это не Unity PBR.

Edit > Array создаёт линейные, радиальные и случайные копии с единым Undo. Полный паритет с ReyondBroom пока не достигнут. В Perforate установлен предел «число отверстий × число сторон ≤ 128»; неразмещаемая или вырожденная геометрия отменяется без частичного изменения карты.

Проверьте операции PK3 и резервные копии, удаление и восстановление файлов, сохранение/отмену текстовых правок, прокрутку больших каталогов, все варианты defaultwall, Array с Undo/Redo и отказ Perforate на чрезмерных параметрах. Дополнительно проверьте clipboard/cursor/WAD drop под Wayland и компиляцию карт на обеих ОС.
