# Alpha 54: настройки и повторное связывание Symmetry

Откройте **Edit → Symmetry → Settings…**. Можно задать угол плоскости с точностью до градуса и собственный центр XYZ. Затем выберите 2/4/8 зеркальных или повёрнутых сторон. Центр сохраняется в карте и остаётся на месте при смене количества сторон. Голубые направляющие показываются для выбранной или открытой группы; их данные кешируются.

**Relink matching existing groups** ищет уже существующие совпадающие группы. При полном совпадении всех сторон геометрия не пересоздаётся — добавляется связь. Если набор не найден, создаются обычные копии. Последующие правки синхронизируют геометрию, материалы и незащищённые свойства энтити. Флаг можно отключить.

Проверьте центр и угол, режимы 2/4/8, редактирование любой стороны, Undo/Redo, повторное открытие MAP, направляющие, связывание готовых копий и зеркальные патчи. [Подробные ограничения и полный список проверок](alpha54.md). Полный перенос всех возможностей ещё не завершён.
