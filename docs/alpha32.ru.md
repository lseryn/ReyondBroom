# FTEBroom alpha.32 — terrain, компиляция и файлы

[English](alpha32.md)

## Что изменилось

- В профиле **When the sky went dark** команды **Edit → Create terrain…** и **ПКМ по сцене → Create terrain here…** добавляют terrain на текущую карту. Задайте Origin и материал, затем нажмите **Add terrain**. Создаётся участок 2×2 секции с привязкой к границам секций; существующие объекты и непустые секции сохраняются.
- Создание terrain и каждый законченный мазок входят в общую Undo/Redo. При сохранении завершается текущий мазок; сохраняются MAP и файлы секций. Переносите их вместе. Save As копирует секции к новой карте.
- Исправлен обычный фоновый Build с внешним WAD. В alpha.31 подготовка WAD работала в явном экспорте, но очередь Build обходила её. Теперь Build копирует загруженные WAD без изменений в `_ftebroom-build/<job>/_ftebroom-wads/wad-N.wad` и передаёт компилятору относительные ASCII-пути. Оригинал не изменяется. WAD должен быть подключён через Add WAD(s) или перетаскивание; одного соседства с MAP недостаточно.
- Исправлена ориентация лицевой стороны патчей при экспорте для Q3Map2. Патчи hotel02 присутствовали в BSP, но были развёрнуты обратной стороной. Исходные контрольные точки и UV сохраняются.
- Превью материалов используют отдельный ограниченный ячейкой 2D-шейдер: деформация мирового материала больше не выносит миниатюру за её границы. В браузере показывается статичное editor image или первое изображение материала; эффекты в сцене сохраняются.
- В **Workspace → Mod file manager** появились **Thumbnail view**, размер плиток, иконки папок/файлов. ПКМ по элементу: Copy, Cut, Paste, Rename…, Open containing directory. Paste вставляет в текущую открытую папку. Копия получает свободное имя, перемещение и переименование не перезаписывают существующий файл.
- MDL/MD3/MD2/IQM можно перетащить из менеджера на сцену: создаётся `func_model` с относительным путём. Мод должен поддерживать этот класс; текстуры модели должны быть доступны в моде. Перетаскивание на папку менеджера перемещает файл. Внешние файлы по-прежнему копируются.
- **Preferences…** перенесены в **Edit**.
- **File → New** открывает выбор профиля и папки/имени новой карты. Предлагается `maps` выбранного профиля. Для Quake 1 и When the sky went dark создаётся `info_player_start`, для Quake 3 — `info_player_deathmatch`. Отмена сохраняет текущий документ, существующие карты не перезаписываются.

**Ограничение:** native terrain остаётся heightfield движка FTE. Q3Map2 не превращает его в Q3 BSP; прежнее ограничение Build для terrain-карт сохраняется. Конвертация terrain в BSP в эту версию не входит.

## Что проверено автоматически

Настоящая очередь Build и точное совпадение пикселей WAD внутри BSP; обе поверхности hotel02 и их ориентация; создание terrain, Undo/Redo, повторное сохранение/открытие с сохранностью брашей, патча и энтити; файловые Copy/Cut/Paste; диалог новой карты; базовые жесты. Отдельный round-trip hotel02 сохранил 2394 браша и два патча. Исходные пользовательские MAP/WAD не изменялись.

## Полный список ручных проверок

Проверяйте на копии карты и в тестовой папке мода.

1. Добавьте terrain на заполненную карту через Edit и ПКМ. Проверьте положение, сохранность объектов, панель Terrain, добавление рядом с уже существующим terrain.
2. Поднимите/опустите, сгладьте, выровняйте, покрасьте terrain и сделайте отверстие. Отмените/повторите каждый мазок. Чередуйте правку браша и terrain: порядок Undo/Redo должен сохраняться. Отмените создание terrain. Сохраните, откройте повторно, затем сделайте Save As в другую папку.
3. Соберите hotel02 и осмотрите обе криволинейные поверхности с лицевой стороны в BSP. Вернитесь в редактирование и проверьте материал и контрольные точки.
4. Подключите concrete_sh.wad с рабочего стола с кириллицей, затем попробуйте копию рядом с MAP. Покрасьте Quake 1 браш, нажмите обычный Build и проверьте текстуру в BSP. Оригинал WAD должен остаться прежним.
5. Откройте материалы с деформацией/анимацией, прокрутите и измените размер браузера. Превью должны оставаться в ячейках; мировые эффекты — работать в сцене.
6. В менеджере переключите список/плитки, размер, откройте папки. Проверьте Copy/Cut/Paste/Rename и конфликт имён. Перетащите модель на сцену, отмените/повторите её создание. Переместите файл в другую папку менеджера и скопируйте внешний файл.
7. Откройте Preferences из Edit. Создайте новую карту каждого из трёх профилей, смените папку, проверьте отмену. Сохраните/откройте и проверьте профиль, класс старта игрока и последующую папку Open/Save.
