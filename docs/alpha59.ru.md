# Alpha 59: выбор GLSL-файла

Открой **Edit → Preferences → Game profile → Game / resources...**, выбери **FTE Custom game**, затем **Editor defaultwall → Custom GLSL file → Browse...**.

В диалоге можно открывать папки, подниматься кнопкой Up, вводить каталог вручную и обновлять список. Показываются `.glsl`-файлы. Выбери файл и нажми Choose GLSL либо сделай двойной клик. Cancel и крестик оставляют прежний выбор.

Примени/загрузи ресурсы профиля: абсолютный путь сохранится и восстановится при следующем запуске. Исходный файл не изменяется. Quake 1 и Quake 3 этот override не используют.

Нужна совместимая с FTE программа defaultwall. Произвольный GLSL другого движка может не работать. Include-файлы ищутся в подключённых игровых ресурсах; соседние файлы автоматически не копируются. Пустой, отсутствующий, нетекстовый файл, другое расширение и размер более 1 МиБ отклоняются. Ошибки синтаксиса GLSL отображает консоль FTE.

## Что проверить

1. Навигацию по папкам, Up, Cancel, крестик и двойной клик; путь с пробелами и кириллицей.
2. Применение шейдера и сохранение выбора после полного перезапуска.
3. Возврат на Current FTE default с перезагрузкой ресурсов.
4. В профилях Quake 1/3 настройка скрыта и override отключён.
5. Сообщения для пустого/отсутствующего файла; исходник остаётся неизменным.
6. Шейдер с include-файлами из ресурсов твоего мода.

Автоматические проверки выполняются на Windows и Arch Linux/Xvfb, включая два запуска процесса. Реальная сессия Wayland этим не проверяется.
