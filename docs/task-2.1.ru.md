# Выделение объектов — 0.5.0-alpha.13

[English](task-2.1.md) · [Общий список проверок](checks-2.1.ru.md)

В основном инструменте клик выделяет объект, клик в пустоту снимает выделение. Ctrl+клик добавляет или убирает объект. При переходе к объектам выделение граней сбрасывается. Можно совместно выделять браши, патчи и точечные сущности. Справа отдельно показывается количество геометрических объектов и сущностей. Скрытые и заблокированные узлы и их потомки исключаются.

Ctrl+протягивание от невыделенного объекта или пустого места добавляет всё под курсором, включая начальный объект. Между позициями курсора проверяется весь путь. Отпускание мыши создаёт один шаг Paint Selection; Escape возвращает прежнее выделение и сохраняет Redo. Ctrl+протягивание от уже выделенного объекта пока ничего не делает: дублирование с перемещением относится к этапу 4.1.

Ctrl+колесо перебирает перекрывающиеся объекты по глубине: от себя — дальше, к себе — ближе. На краях списка перебор останавливается. Если ничего из попавшего под курсор не выделено, выбор начинается с ближайшего/дальнего соответственно. Закрытая группа считается одним кандидатом. Каждый переход отменяется одним Undo. Ctrl+Alt+колесо по-прежнему меняет сетку. Обычный клик в 2D выбирает объект с меньшей видимой площадью грани.

Клик по содержимому закрытой группы выделяет её доступные объекты. Двойной клик открывает внешнюю закрытую группу; вложенные открываются по одному уровню. Двойной клик внутри открытой группы выделяет соседей с тем же родителем (Ctrl добавляет). Двойной клик снаружи закрывает один уровень и выделяет закрытую группу. Название открытой группы видно справа. Undo/Redo восстанавливают также контекст группы и выделение нескольких сущностей. Создание/перегруппировка групп остаются этапом 15.2, преобразования нескольких объектов и дублирование — последующими этапами.

Выделение не меняет геометрию, материалы, патчи и свойства сущностей в MAP. Редактирование и удаление точечных сущностей — отдельные этапы; здесь добавлено именно выделение. Shift+клик по одной грани сохранён; расширенное выделение граней будет в 2.2.

Также исправлена глубина поиска геометрии для 2D-каркаса: объекты вне рабочей плоскости должны оставаться видимыми.

**Launch-Checks.cmd → 8** открывает пять синих брашей, три перекрывающихся красных, пару зелёных в группе и две точечные сущности. Ручные проверки файлового браузера и камеры из alpha.12 ещё не приняты и включены в общий список.
