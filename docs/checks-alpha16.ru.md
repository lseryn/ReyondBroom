# Полный список проверок alpha.16

[English](checks-alpha16.md) · [Список фичей](alpha16.ru.md)

Распакуй ZIP целиком в новую папку, работай на копиях карт. В `Launch-Checks.cmd` выбери **B** для новых операций с брашами. Остальные сцены доступны там же.

1. **Проект и файлы:** Quake 3, настоящий baseq3, текстуры/шейдеры из PK3 и папок. В File → Open и Save As должна быть навигация по каталогам. Отмена диалога, открытие другой карты, сохранение/повторное открытие. Рабочая панель остаётся видимой.
2. **Камера и виды:** WASD/QX, RMB, orbit/pan, колесо и сетка, показ/отключение привязки, два/четыре вида, связанные камеры, разделители. Ввод текста в поле не двигает камеру.
3. **Выделение:** Ctrl-клики, рисование выделения, выбор сквозь перекрывающиеся объекты, группы и точечные сущности; Shift-клик грани, Ctrl+Shift и coplanar flood. Команды All/Invert/Siblings/Touching/Inside/Tall, выбор по строке MAP. Скрытые/заблокированные объекты не попадают в результат.
4. **Создание:** сними выделение, создай браши при сетке 8/16/32. Высота равна ячейке. Модификаторы квадрата/куба, глубина в 2D, открытая группа, Escape, Undo/Redo.
5. **Перемещение и копии:** несколько брашей и смешанное выделение с патчем/сущностью; XY, Alt-Z, клавиатурные сдвиги. Ctrl-драг и Ctrl+D создают независимые копии. Дублируй вложенную группу и измени только одну копию. Delete/Undo восстанавливают всё выделение.
6. **Буфер:** Copy/Cut/Paste внутри редактора и между двумя экземплярами; вставка на исходное место; MAP-фрагмент из текстового редактора. Проверь свойства сущностей, группы и патчи после сохранения. Скопируй атрибуты одной грани на другую, затем Undo.
7. **Материалы:** грань/целый браш, применение текстуры, offsets, Scale X/Y, angle, смешанные значения и относительные шаги. Каталоги, used, поиск, выделение/замена по материалу, флаги и точные 32-битные значения. Сохранение и Undo/Redo сохраняют результат.
8. **Текстурное выравнивание:** Left/Right/Top/Bottom, Edge, Fit H/V, Auto. Повторный Fit, Ctrl для долей, Shift для обратного цикла. Клавиатурный сдвиг/поворот/отражение/reset. С одной выделенной гранью протяни Alt на другую; сравни Alt+Shift и Alt+Ctrl.
9. **Rotate:** выдели браши/патч/сущность и нажми R. Дуга примерно на 40° при шаге 15° даёт 45°. Перенеси/сбрось центр, введи угол числом, проверь Escape и Undo/Redo. Сравни Texture Lock. У света правильно меняется yaw в `mangle`.
10. **Extrude:** выйди из модального инструмента, выдели куб, Shift-драг верхней/боковой грани. Жёлтая подсветка, привязка, размеры предпросмотра, один Undo, Escape. Вдавливай до противоположной грани: браш должен остановиться до схлопывания. В 2D тяни ребро. У двух соприкасающихся выделенных кубов двигай общую стенку: суммарный объём не меняется.
11. **Split:** Shift+Ctrl-драг наружу сохраняет исходный браш и выделяет новую часть. Внутрь — укорачивает исходный и выделяет отрезанный объём. Один Undo возвращает геометрию и выделение. Повтори внутри группы.
12. **Stamp:** Shift+Ctrl+Alt-драг наклонной грани создаёт призму без изменения исходника. Сравни со Split. Общая противоположная стенка двух брашей не должна создавать перекрывающиеся части.
13. **Старый Clip:** выдели браш, C, две точки на одной грани — должна появиться секущая плоскость. Переключи стороны, посмотри прозрачную отбрасываемую часть. Apply, Undo/Redo, Escape, Delete. Расширенная переделка Clip ещё впереди.
14. **Сохранность карты:** сохрани и открой карту с брашами, патчами, группами и сущностями; сравни форму, UV, материалы, флаги и свойства. Проверь привычный масштаб интерфейса Windows.

При ошибке полезны: действие, модификаторы, вид, размер сетки, ожидаемый/фактический результат и маленькая тестовая MAP.
