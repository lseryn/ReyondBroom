# Alpha 60: профиль, первоначальная настройка и полноэкранный режим

Первоначальная настройка теперь состоит из четырёх шагов в одном окне: **язык → тема → игровой профиль → ресурсы**. Размер и положение окна не меняются, кнопки находятся в постоянном нижнем блоке. Четыре плитки показывают цвета интерфейса: **Modern Dark**, **Modern Light**, **Retro Light**, **Retro Dark**. Выбор применяется сразу и сохраняется. Изменить тему позже можно через **View → Interface theme**.

![Выбор темы](../screenshots/setup60-themes.png)

**View → Fullscreen** включает и отключает полноэкранное окно без перезапуска рендера и загрузки карты заново. Несохранённые изменения сохраняются в памяти. Режим запоминается; по умолчанию используется оконный. В Linux используется протокол оконного менеджера X11, в том числе для текущей сборки под XWayland.

При применении ресурсов **FTE Custom game** включается `r_glsl_offsetmapping 1`; эта настройка передаётся и предпросмотру мода. При переходе к другому профилю восстанавливается прежнее значение редактора. Файлы мода и исходные GLSL не изменяются. Визуальный эффект зависит от поддержки offset mapping самим материалом.

Убрано повторное обновление определений энтити и перестроение кешей геометрии при неизменившихся материалах/определениях. На тестовой копии hotel02 в alpha.59 было воспроизведено зависание примерно на минуту; с исправлением повторные применения прошли без него. Вылет процесса в этом тесте не воспроизвёлся, поэтому устранение всех причин вылетов пока не подтверждено. Исходная карта и мод не изменялись.

## Проверка

1. В новой установке пройти все шаги, вернуться назад, выбрать каждую тему. Проверить неизменный размер окна и сохранение темы после перезапуска.
2. На hotel02 несколько раз применить настройки профиля и режимы defaultwall/GLSL. Проверить отображение, выделение, несохранённые изменения и Undo.
3. Изменить папку ресурсов или определения энтити и убедиться, что новые данные появляются в браузере.
4. Включить Fullscreen с несохранённой картой, вернуться в окно. Проверить курсор, панели, ввод текста, миниатюры и сохранение режима после перезапуска.
5. Для FTE Custom проверить значение `r_glsl_offsetmapping` и материалы в MAP/BSP и предпросмотре мода. Для Quake 1/3 проверить восстановление прежнего значения.

Автоматические проверки Linux выполнялись в Arch с Xvfb/Openbox. Работу на настоящем Wayland-композиторе нужно подтвердить отдельно.
