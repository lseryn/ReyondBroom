# Alpha 65 — панель инструментов и перезапуск рендера

Compile, Setup compile, Show BSP и Preview mod идут сразу после кнопок инструментов слева. При нехватке ширины элементы переносятся на следующую строку.

Sculpt, Bezier Bend, Polygon Cut, Polygon Spawn, Spin и Rotate Grid по умолчанию скрыты за стрелкой. В горизонтальной панели группа раскрывается вправо, в вертикальной — вниз. Сворачивание не выключает активный инструмент. Меню и горячие клавиши сохраняются.

При закреплении Tools сбоку выбор формы, Shape settings, Replace selection и поля перемещения подстраиваются под ширину панели. Подписи параметров находятся над полями ввода.

Колесо над UV-текстурой масштабирует её без прокрутки инспектора. В Modern Dark у полей материалов и UV теперь различимые фон и рамка.

Apply MSAA восстанавливает ImGui и его изображения после перезапуска рендера, сохраняя редактируемую MAP-карту и Undo/Redo. Для FTE Engine terrain и предпросмотра мода требуется перезапуск приложения.

Проверить: раскрытие группы в горизонтальной и боковой панели; перенос элементов при сужении; параметры формы и перемещения слева и справа; положение Compile; колесо и поля UV; Apply MSAA с несохранёнными изменениями и последующим Undo/Redo.

Кнопка **Форма / перемещение (Shape / move)** раскрывает настройки создания и перемещения брашей; блок также свернут по умолчанию. У Compile, Setup compile, Show BSP и Preview mod есть иконки и текстовые подписи.

Подсветка по Shift рисует периметр грани без диагоналей. При компиляции несохранённой карты появляется заметное сообщение сверху вьюпорта. В Windows предпросмотр мода запускается скрыто с индикатором загрузки; дочернее окно больше не захватывает системную мышь самостоятельно. Встроенный предпросмотр по-прежнему доступен только в Windows; Linux сохраняет внешний запуск мода.

Дополнительно проверить: Shift на разных гранях куба; Compile до сохранения карты; загрузку Preview mod, плавность камеры, игровой ввод, Escape и возврат к редактированию. Проверки UI/UV прошли на Windows и Linux; тест жестов и сохранения hotel02 — на Windows. После сохранения и открытия осталось 2394 браша и 2 патча, исходный файл не изменялся.

Кнопки Compile, Setup compile, Show BSP и Preview mod имеют одинаковую высоту с инструментами; иконки и надписи выровнены по центру по вертикали. Кэш геометрии граней использует общие буферы вместо отдельных выделений памяти на каждую грань.

Стрелки раскрытия, Shape / move, Int, Texture Lock и UV Lock также выровнены по высоте с кнопками инструментов.
