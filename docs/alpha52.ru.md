# Alpha 52: папки текстур и WAD для компиляции

В профиле **Quake 1** откройте **Material → Texture folders / compile WAD…**. Выберите папку с PNG/JPEG/TGA/BMP и нажмите **Import / rebuild folder**. Подпапки включаются автоматически; исходные изображения не меняются.

При необходимости выберите палитру LMP, PCX или BMP; пустое поле означает палитру активной игры. **Preview palette** показывает цвета. Палитра должна совпадать с игровой: внутри WAD2 она не хранится. Изображения приводятся к размерам 16–512, степеням двойки, и четырём mip-уровням. Используются первые 224 цвета; прозрачность накладывается на чёрный фон. Для длинных имён и подпапок создаются короткие стабильные имена; таблица соответствия сохраняется рядом с WAD.

Готовый WAD подключается к материалам и автоматически попадает в безопасный каталог ресурсов компилятора. Конвертация идёт в фоне с прогрессом и отменой. Повторная сборка оставляет предыдущую копию `.previous`. Папки и палитры сохраняются; **Rebuild all registered folders** пересобирает весь список. После изменения исходных изображений нужна ручная пересборка. Закрытие окна не отменяет фоновую задачу — для отмены есть отдельная кнопка.

Проверьте импорт нескольких форматов и подпапок, нестандартные размеры, длинные имена, предпросмотр палитр, ошибочную палитру, отмену, повторную сборку и восстановление списка после перезапуска. Покрасьте браш новой текстурой, соберите карту и проверьте её в BSP. Повторите на Windows и Linux, включая маленькое окно.

Ограничения и подробный список проверок: [English documentation](alpha52.md). Полный перенос возможностей продолжается: [список соответствия](reyond-parity.md).
