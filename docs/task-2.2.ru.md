# Этап 2.2 — выделение граней

[English](task-2.2.md) · [Полный список проверок](checks-2.2.ru.md)

Windows preview **0.5.0-alpha.14** добавляет выделение граней в перспективе.

| Жест | Результат |
| --- | --- |
| Shift+клик | Заменить выделение одной гранью |
| Ctrl+Shift+клик | Добавить или убрать грань |
| Shift+двойной клик | Выделить все грани браша |
| Ctrl+Shift+двойной клик | Добавить все грани браша |
| Shift+Alt+двойной клик | Выделить связную область граней в одной плоскости |
| Ctrl+Shift+Alt+двойной клик | Добавить эту область |
| Ctrl+Shift+протягивание | Выделять грани под курсором, если до начала уже выделена хотя бы одна грань |
| Ctrl+Shift+A / клик в пустоту | Снять выделение |

Ctrl+Shift+клик по уже выделенному целому брашу переводит выделенные браши в выделение граней и исключает нажатую грань. Такой клик по невыделенному брашу начинает новое выделение. Материал, масштаб и угол применяются только к выбранным граням; выделение целого браша по-прежнему применяет их ко всем граням.

Протягивание отменяется одним Undo. Escape восстанавливает исходное выделение и сохраняет ветку Redo. Выделение не меняет геометрию MAP. Грани имеют красную полупрозрачную заливку и контур, справа показано их количество.

Заливка проходит через общее ребро или перекрытие положительной площади. Зазор, касание одной вершиной, другая плоскость, скрытые и заблокированные объекты не соединяют область. При более чем 4096 подходящих кандидатов операция отменяется без изменения выделения. Поддержаны индексы граней 0–63: последующие грани не выбираются, внизу появляется предупреждение. Выделение всех граней большого браша выбирает первые 64 и показывает предупреждение. Жесты граней работают только в 3D. Дальнейшее оформление выделения относится к этапу 2.3.

Увеличен буфер движка для передачи изменения одного сложного браша. Проверяются браши с 64/65 гранями и отмена изменения материала. Сетевое совместное редактирование этим не заявляется.

Готовая сцена: **Launch-Checks.cmd → 9**. Alpha.12 и alpha.13 всё ещё ожидают ручной проверки; alpha.11 принята.
