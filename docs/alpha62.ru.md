# Alpha.62: автоматическая загрузка компонента конвертации

Первая операция **Bake and convert** для FBX, GLB/glTF, BLEND, SMD или DMX автоматически скачивает переносной Blender 5.0.0 с `download.blender.org`. В окне конвертации отображаются скачивание, проверка и распаковка. Затем выбранная конвертация продолжается автоматически. Следующие конвертации используют кэш, в том числе без сети. Устанавливать Blender или настраивать путь не нужно.

В Windows используется встроенный PowerShell. В Linux нужны Python с фильтром распаковки `tarfile data` (рекомендуется 3.12+) и обычные системные библиотеки Blender. Нужны примерно 400 МБ трафика и 4 ГиБ свободного места. Контрольная сумма SHA-256 закреплена отдельно для каждой платформы. Незавершённая загрузка не устанавливается. После ошибки можно повторить **Bake and convert**. Менеджер обновлений сохраняет кэш `downloads`.

Нативные форматы FTE не вызывают загрузку Blender. Форматы экспорта и ограничения прежние: Quake MDL, MD3, статический OBJ+MTL. [Подробности импорта](model-import64.ru.md).

## Что проверить

1. В отдельной чистой установке перетащить GLB/FBX в Mod file manager, подтвердить потери формата и нажать **Bake and convert**. Должны появиться прогресс загрузки и автоматическая конвертация без выбора пути Blender.
2. Проверить текстуры, размер, положение и анимацию результата.
3. Повторить конвертацию без сети: должен использоваться кэш.
4. Первую загрузку попробовать без сети, затем подключить сеть и повторить после ошибки.
5. Убедиться, что нативная конвертация MDL/MD3 не требует скачивания Blender.

## Предложение импорта Source-проекта (ещё не реализовано)

Отдельная команда **Import Source project**: выбрать основной QC и упорядоченный список папок моделей, анимаций и материалов. QC читается как описание зависимостей, его команды не исполняются. Проверяются includes, циклы, недостающие файлы и неоднозначные совпадения имён.

Далее выбрать bodygroups, скины, sequences и LOD; проверить совместимость скелетов; однократно применить трансформации из QC; запечь анимации и объединить меши в один Quake MDL с палитровым атласом. Размер и начало координат должны быть явными. В отдельном отчёте сохранить диапазоны кадров и потери: Quake MDL не хранит всю семантику Source QC, события, физику и произвольные bodygroups. Для этого ещё нужны полноценный разбор зависимостей QC и чтение VMT/VTF. Простое перетаскивание нескольких папок пока не собирает их в единую модель.
