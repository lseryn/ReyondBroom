# Alpha 47: Polygon Cut/Spawn и связанная симметрия

Перенос продолжается. Полное соответствие ещё не достигнуто; остаток указан в [списке различий](reyond-parity.md).

## Polygon Cut / Polygon Spawn

Выберите Tools → Polygon Cut для разрезания 1–64 выделенных выпуклых брашей либо Polygon Spawn для создания новых. Расставьте точки контура; первый клик в перспективе задаёт плоскость грани, а в пустоте — горизонтальную плоскость. В 2D используется плоскость текущего вида. Замкните контур кликом по первой точке или Close contour. Точки можно перетаскивать.

Depth задаётся в шагах сетки: 0 — насквозь, положительное значение — глубина внутрь браша от плоскости контура. Keep cutout сохраняет вырезанные объёмы вместе с окружающими фрагментами. Spawn создаёт объём толщиной в одну ячейку сетки с текущим материалом нового браша. Вогнутый контур разбивается на выпуклые браши.

Apply/Enter применяет результат одной операцией Undo. Escape во время перетаскивания возвращает точку; вне жеста закрывает инструмент. Backspace размыкает контур, затем удаляет последнюю точку. Reset очищает контур. До Apply карта не меняется. Ограничения: 64 точки, 512 выходных брашей. Самопересечения и вырожденные контуры отклоняются. Разбиение на части может отличаться от специализированного разбиения UltimateTrenchBroom.

## Симметрия

Выделите объекты → Edit → Symmetry → 2/4/8 sides (Mirror/Rotate). Создаются связанные группы вокруг центра исходного выделения по вертикальной оси. Mirror чередует отражения и повороты, Rotate только поворачивает.

Откройте группу любой стороны и меняйте её содержимое — изменения синхронизируются. Закрытую группу можно двигать отдельно. Выбор другого режима для выделенной закрытой группы перестраивает весь набор. Создание, перестройка и правки поддерживают Undo; связи сохраняются в MAP. Separate Linked Groups разрывает связи выбранных групп. Лимит — 2048 объектов с учётом копий.

Автоматическое связывание уже существующих зеркальных объектов и направляющие плоскости оригинального инструмента ещё не перенесены. При перестройке выбранная сторона становится исходной, ориентация задаётся горизонтальными осями мира.

## Что проверить

1. Прямоугольный и Г-образный контуры в перспективе и 2D; правильность плоскости.
2. Перетаскивание, Backspace, Escape, Reset и отмену без изменения исходника.
3. Сквозной/неглубокий рез, Keep cutout, разные сетки, несколько брашей и брашевую энтити; Apply/Undo/Redo.
4. Spawn: материал, толщину в одну ячейку, вогнутый контур. Самопересекающийся контур должен отклоняться.
5. Симметрию 2/4/8, Mirror/Rotate, правки из каждой стороны, материалы и энтити, Undo/Redo.
6. Перестройку режима, сохранение/открытие карты, разрыв связей.
7. Обычные перемещения XY/Alt-Z, Clip, удаление и ввод текста на обеих ОС. Переключайте 2D/перспективу и раскладки из нескольких видов: ближняя геометрия не должна исчезать.
8. Большие операции: отказ не повреждает карту, консоль не переполняется сообщениями сетевой очереди.

Автотесты проверяют геометрию, жесты, историю, симметрию и атрибуты MAP. Linux-проверки выполняются в Arch через Xvfb/software OpenGL; живой Wayland-сеанс здесь не проверялся.
