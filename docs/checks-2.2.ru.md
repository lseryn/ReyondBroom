# Полный список проверок — alpha.12 + alpha.13 + alpha.14

[English](checks-2.2.md) · [Изменения](task-2.2.ru.md)

Распакуй весь ZIP в новую папку. Alpha.11 принята. Alpha.12 и alpha.13 пока не проверены — ниже собраны все их пункты вместе с новым этапом.

## Грани — alpha.14

Запусти **Launch-Checks.cmd → 9**, дождись перспективы. В центре четыре соприкасающихся синих куба. Красный касается их только углом; зелёные отделены зазором или имеют другую высоту. Создавать patch для этих проверок не нужно.

1. Shift+клик по верхней грани: подсвечена только она, справа Face selection: 1 faces. Повтори на боковой грани: прежняя снимается.
2. Ctrl+Shift+клик по другой грани добавляет её. Повторный клик убирает. Убери последнюю грань: выделение должно стать пустым. Проверь Undo/Redo.
3. Обычным кликом выбери целый синий браш, Ctrl+кликом добавь второй. Ctrl+Shift+клик по одной их грани: должно остаться 11 граней. Undo возвращает два целых браша. Такой клик по невыделенному брашу выбирает только одну его грань.
4. Shift+двойной клик по синему кубу: 6 граней. Ctrl+Shift+двойной клик по другому: 12. Проверь Undo/Redo.
5. Shift+Alt+двойной клик по верхней грани синего куба: выделяются ровно четыре синие верхние грани. Красный и зелёные не входят. Ctrl+Shift+клик снимает одну: остаётся 3; Undo возвращает 4.
6. Выдели верхнюю грань отдельного зелёного, затем Ctrl+Shift+Alt+двойной клик по синей области: должно быть 5 граней.
7. Выдели одну синюю верхнюю грань. Зажми Ctrl+Shift и проведи по остальным синим верхним граням: они добавляются. Один Undo отменяет всё протягивание, Redo возвращает результат. Во время нового протягивания нажми Escape до отпускания мыши: прежнее выделение восстанавливается.
8. На одной грани выбери другой материал, измени Scale X/Y и Angle. Остальные грани не должны меняться. Повтори на нескольких выбранных гранях, затем на целом браше; проверь Undo/Redo.
9. Клик в пустоту и Ctrl+Shift+A снимают выделение. В XY/XZ/YZ Shift-жесты не должны создавать выделение граней.
10. Сохрани копию и открой её: геометрия, материалы и свойства сущностей сохранены. Само выделение в MAP не сохраняется.
11. Если есть карта со скрытыми/заблокированными объектами, проверь, что заливка и протягивание их не выбирают. Сложные браши с 64+ гранями проверены автоматически; готовить их вручную не требуется.

## Выделение объектов — 2.1

Запусти **Launch-Checks.cmd → 8**, дождись четырёх видов. Синий ряд и красную стопку удобнее проверять в XY; обычное выделение повтори и в перспективе.

1. Ctrl+клик по трём синим брашам: счётчик 3. Повторный Ctrl+клик по среднему: 2. Undo/Redo возвращают 3/2. Обычный клик заменяет выделение, клик в пустоту снимает всё.
2. В перспективе выдели грань через Shift+клик, затем другой браш через Ctrl+клик. Должны остаться только целые объекты.
3. Сними выделение, зажми Ctrl и протяни через все пять синих брашей, начиная с первого невыделенного. Должно выделиться 5; один Undo отменяет всё протягивание, Redo возвращает пять. Повтори с началом в пустоте. Начни новое протягивание и нажми Escape до отпускания мыши: прежнее выделение должно восстановиться.
4. Ctrl+протягивание от уже выделенного браша пока ничего не перемещает и не дублирует — это будущий этап 4.1.
5. В XY наведи курсор на три перекрывающихся красных браша. Ctrl+колесо от себя выбирает объекты глубже, к себе — возвращает назад. В соседних видах видно, какой браш по высоте выбран. Каждый переход отменяется Undo/Redo; сетка не меняется. Ctrl+Alt+колесо всё ещё меняет сетку.
6. Кликни один зелёный браш: выделяются оба члена группы. Двойной клик открывает группу, справа видно её название. Теперь обычный клик выбирает один браш, двойной — обоих соседей. Двойной клик в пустоту вне группы закрывает её и выделяет группу. Проверь Undo/Redo.
7. Через Ctrl+клик выдели две рамки точечных сущностей ниже ряда; можно добавить синий браш. Обе рамки подсвечены, счётчик сущностей — 2. Проверь Undo/Redo и Ctrl+U: в кадр должно помещаться всё выделение. Удаление сущностей не входит в этот этап.
8. В перспективе и всех 2D-видах проверь соответствие клика видимому объекту; геометрия вне рабочей плоскости должна быть видна. Повтори выделение на готовом патче из сцены 3 — создавать патч не нужно.
9. На карте со скрытым/заблокированным слоем или группой их содержимое не должно выделяться кликом, протягиванием или перебором.
10. Сохрани копию карты и открой её: геометрия, материалы, патчи и свойства сущностей должны сохраниться. Само выделение в MAP не записывается.

## Alpha.12 — всё ещё ожидает проверки

## Open и Save As

1. Выбери File → Open, затем повтори через Ctrl+O. Должно открыться окно выбора файла.
2. Проверь Up, двойной клик по папке, выбор диска Drive, ввод пути в Folder и кнопку Go. В списке должны быть папки и `.map`; проверь прокрутку длинного списка.
3. Открой карту вне папки редактора, желательно с пробелами и кириллицей в пути. Выдели файл и нажми Open. Проверь геометрию, материалы, сущности и готовый patch; справа должны отображаться исходное имя и путь.
4. Открой браузер и нажми Cancel. Карта, выделение и признак несохранённых изменений должны остаться прежними.
5. Измени карту. Выбери File → Save As или Ctrl+Shift+S, перейди в другую папку, введи новое имя без расширения и нажми Save. Должен появиться новый `.map`, оригинал не должен измениться.
6. Измени ещё что-нибудь и нажми Ctrl+S. Сохранение должно идти в новый выбранный файл без браузера. Открой его повторно и проверь изменение.
7. Сохрани через Save As поверх существующего файла. Должно появиться подтверждение. Cancel сохраняет старый файл; повторная попытка с Replace заменяет его.
8. Создай новый документ, добавь бокс и нажми Ctrl+S: редактор должен спросить место сохранения. Cancel оставляет документ несохранённым.
9. Измени документ и открой другую карту. Проверь Save, Don't Save и Cancel в предупреждении. Save сначала сохраняет текущую карту; Cancel оставляет её открытой.
10. Введи несуществующую папку или имя отсутствующей карты. Должна появиться понятная ошибка, текущая карта остаётся. Если есть возможность, попробуй сохранить в недоступную для записи папку: признак несохранённых изменений не должен пропасть.
11. Пока вводишь имя файла, WASD, Delete и другие клавиши не должны управлять сценой.

## Фокус и координаты камеры

Запусти Launch-Checks.cmd → 7 — четыре вида.

1. Выдели куб и нажми Ctrl+U. Камера плавно перемещается примерно за 150 мс, направление взгляда не меняется, весь объект помещается в 3D-виде.
2. Повтори с длинным или высоким брашем и после изменения размеров вида. Запусти Ctrl+U с фокусом в XY, XZ и YZ: все 2D-виды центрируются на выделении, их масштаб сохраняется.
3. Сними выделение и нажми Ctrl+U: камера не должна прыгать к старому выделению.
4. Выбери View → Move Camera to…, введи `111 -222 333`, нажми Move. Меняется только позиция 3D-камеры. Повтори ввод других координат и нажми Cancel: камера остаётся на месте.
5. Введи координату за пределами ±65536: Move должна быть недоступна. Ввод в поля не должен управлять камерой.
6. После фокуса попробуй обычное управление камерой. Оно должно сразу работать. Навигация не должна создавать шаг Undo или менять геометрию карты.

## Короткая повторная проверка

- Создание, перемещение и удаление браша; Undo/Redo.
- Clip двумя точками на боковой грани; полупрозрачная отсекаемая часть.
- Шаг и видимость сетки; Alt/Shift при перемещении в 2D.
- Материалы, масштаб/угол текстур, разделители четырёх видов и постоянная панель.

Создавать patch или проверять point-файлы в этом обновлении не нужно. Если что-то сломается, укажи пункт, ожидаемое и фактическое поведение; при необходимости приложи скриншот.
