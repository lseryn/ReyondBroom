# Импорт моделей и скины

Перетащите модель из системного файлового менеджера в Mod file manager редактора. Откроется предложение конвертации. Несколько файлов обрабатываются очередью; закрытие окна пропускает текущий файл. Исходник не перезаписывается.

* Quake 1 предлагает Quake MDL со встроенной текстурой в палитре активной игры.
* Quake III предлагает MD3 с копированием текстур в TGA.
* FTE Custom game предлагает реализованные экспортёры: MDL, MD3 и OBJ + MTL. Это **не все форматы**, которые движок умеет читать: для записи каждого формата нужен отдельный экспортёр.

Нативные форматы FTE используют извлечение геометрии движком. `.md5` трактуется как MD5Mesh. Для Half-Life MDL v10 используются вычисления костей его рендера; сопутствующие файлы текстур и анимаций должны находиться рядом с оригиналом. Экспортируются стандартные bodygroups и первый скин, события модели не выполняются.

При первой конвертации FBX, GLB, glTF, BLEND, SMD или DMX кнопка **Bake and convert** автоматически скачивает переносной Blender 5.0.0, проверяет закреплённую SHA-256, распаковывает его и продолжает конвертацию. В окне отображается прогресс скачивания и распаковки. Нужны несколько сотен МБ трафика и 4 ГиБ свободного места. В дальнейшем используется скачанная копия, в том числе без сети. Устанавливать Blender и указывать путь вручную не нужно. После ошибки скачивания можно повторить конвертацию. В Windows используется PowerShell, в Linux — Python 3.12+ (либо версия с фильтром tarfile data) и обычные системные библиотеки Blender. Кэш находится рядом с настройками редактора в `downloads/blender-5.0.0`. Установленный отдельно Blender и файлы игры не изменяются.

Для SMD/DMX используется включённый в комплект Blender Source Tools. Не найденные зависимости Source VMT/VTF необходимо подготовить или предоставить как PNG/TGA/JPEG. При отсутствии текстур конвертация останавливается с объяснением.

Blender работает в фоне, без автоматического исполнения скриптов из файлов. Геометрия запекается с мировыми трансформациями, базовый цвет — в текстуры 512×512. Одна единица Blender соответствует единице карты. Автоматического центрирования, изменения размера или упрощения сетки нет. Укажите начальный кадр, количество кадров и частоту выборки. Для нативных моделей выбирается последовательность; `-1` берёт последовательные позы MDL/MD2.

Перед сохранением нужно подтвердить потери: кости, теги, события и альтернативные скины не сохраняются в исходном виде, выбранная анимация запекается. Прозрачность, normal maps и эффекты игровых шейдеров не воспроизводятся палитровым скином Quake. В MDL каждый материал получает область 256 пикселей, цвета fullbright исключены. Координаты MDL имеют 8-битную точность на ось в пределах всей анимации; MD3 — точность 1/64 единицы и диапазон −512…511,984. Выход за пределы вызывает ошибку, а не скрытое уменьшение модели. OBJ сохраняет только первую позу. Существующие файлы не заменяются.

Двойной клик по модели открывает Model Viewer. **Skin** переключает встроенный скин, **Material set (.skin)** — найденный внешний набор материалов. **Skin texture** показывает выбранный встроенный скин Quake MDL отдельно. Просмотр не меняет исходник или энтити карты.

Тесты охватывают трансформированные анимированные BLEND/FBX/GLB, точность MDL, переносимость текстур MD3 и искусственный Half-Life MDL v10. Модели с процедурными материалами, отдельными анимациями и нестандартными UV необходимо дополнительно проверять визуально.
