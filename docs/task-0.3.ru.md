# Модель документа и предпросмотр — 0.5.0-alpha.3

[English](task-0.3.md)

В Clip отсекаемый объём показан прозрачным оранжевым цветом, сохраняемый — непрозрачным с голубым контуром. Ctrl+Enter переключает стороны; Enter применяет разрез. В режиме Both сохраняются обе части. Некорректная или касательная плоскость не скрывает исходный браш.

При перемещении исходное изображение браша скрывается. Escape отменяет перенос и возвращает исходный браш без изменения карты.

Панель Document показывает имя карты и `*` при несохранённых изменениях истории. После сохранения и Undo до сохранённого состояния звёздочка исчезает; Redo и новая правка после Undo возвращают её.

File New/Open/Close/Exit и обычное закрытие окна предлагают Save / Don't Save / Cancel. New и Close открывают пустой документ. Сохранение сначала записывает временный MAP, а затем заменяет целевой файл; при ошибке документ остаётся несохранённым. В поле Name вводится имя без пути и расширения, латинскими буквами, цифрами, дефисом или подчёркиванием.

Автокопии создаются каждые 10 минут в `ftebroom/autosave/`, до 50 на имя карты. Самая старая копия заменяется. Интервал задаётся `ftebroom_autosave_interval` в минутах, 0 отключает копии. Автокопия не сбрасывает признак изменений. Для открытия скопируйте её в `ftebroom/maps/`.

Добавлено дерево world → слои → группы/сущности/браши/патчи, чтение `_tb_*`, ссылки на субмодели движка и обновление идентификаторов при Undo. Это основа документа: интерфейс управления группами/слоями и применение флагов скрытия/блокировки во всех инструментах пока впереди. Прямые изменения через старые консольные команды вне истории не отслеживаются. Прямой `mapedit`, принудительный выход и завершение процесса обходят защиту интерфейса.

Тесты проверяют сохранение полей и принадлежности объектов, граней брашей, размеров/контрольных точек/UV патчей, состояния сохранения и автокопии. FTE нормализует служебные поля заголовка патча, поэтому побитовое совпадение его форматирования не заявляется.

## Что проверить вручную

1. C → две точки → Ctrl+Enter: прозрачная сторона должна меняться. После Enter удаляется именно она.
2. Перенесите выделенный браш: исходного изображения быть не должно. Escape возвращает его.
3. Сохраните карту, переместите браш, сделайте Undo и Redo; проверьте звёздочку рядом с именем.
4. С несохранённой тестовой картой проверьте New/Open/Close/Exit и крестик окна. Сначала Cancel, затем Save.
