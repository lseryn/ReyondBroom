# Alpha 57: список объектов карты

Открой **View → Entity list**. Здесь показаны уже размещённые энтити и группы. Для энтити используется targetname, если он задан, иначе classname. Поиск работает по имени, классу и типу Group/Entity.

Двойной клик выделяет объект и наводит камеру. Для вложенного объекта открывается содержащая его группа. Скрытые, заблокированные или отфильтрованные объекты не включаются автоматически — сначала разреши их редактирование.

## Что проверить

1. Поиск именованных групп, точечных и брашевых энтити; поиск по классу и имени.
2. Двойной клик на объект внутри закрытой группы, затем на объект в другой группе. Выделение и наведение камеры в 3D/2D.
3. Переименование, удаление, Undo/Redo и повторное открытие карты: список должен обновляться.
4. Скрытый или заблокированный слой: двойной клик не должен обходить блокировку.
5. Поиск и прокрутка на большой карте без постоянных пересканирований в состоянии покоя.
