# Alpha 63 — загрузка модов Quake

Реестр моделей движка расширяется по мере необходимости вместо аварийного завершения на 8192 именах. Адреса моделей и их индексы остаются стабильными; повторные запросы не создают дубликаты. Поиск по имени использует хеш-таблицу.

При смене ресурсов Quake 1 обновляются модели, в том числе ранее не найденные. Геометрия редактируемой MAP и брашевые подмодели сохраняются.

Если мод не содержит `gfx/palette.lmp`, для маппинга используется стандартная палитра FTE. Палитра самого мода имеет приоритет. Одинаковую палитру используют WAD-браузер, скины моделей, импорт изображений и конвертация MDL.

Выберите папку AD с PAK-архивами. `ad_1_8.def` обнаруживается автоматически. Соседняя папка `id1` подключается как база, ресурсы AD имеют приоритет. Поле выбора папки мода остаётся единственным; исходные файлы мода не изменяются. WAD-файлы для маппинга добавляются отдельно: в релизе AD их нет. Для игры в AD нужны базовые ресурсы Quake; запасная палитра их не заменяет.

## Что проверить

1. Подключение AD и наличие его энтити в браузере.
2. Модель игрока, её скин и анимацию в Model viewer.
3. Несколько переключений AD → LibreQuake → AD без вылета и со сменой моделей.
4. Добавление WAD, сохранение и компиляцию небольшой карты, просмотр BSP.
5. Предпросмотр игры с оригинальным `id1` рядом с AD и возврат в редактор.
6. Открытие крупных карт и существующих проектов Quake III/FTE Custom.

Автоматические проверки описаны в [английской версии](alpha63.md).
