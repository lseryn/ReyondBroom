# Перетаскивание UV и привязка к краям

Текстура следует за курсором с учётом поворота, масштаба, зеркальных осей и сдвига UV.
Холст сразу показывает преобразование, передаваемое редактору, без ожидания следующего
обновления QC. Отпускание кнопки учитывает последнее положение курсора. Escape отменяет
жест, Undo отменяет всё перетаскивание целиком.

Привязка выбирает ближайшую вершину грани к линии текстурной сетки отдельно по каждой
оси. Порог — восемь логических пикселей с учётом зума и масштаба интерфейса. При выходе
из зоны привязки дробное смещение сохраняется. Ctrl временно отключает привязку при
перемещении и масштабировании. Вращение выполняется круговым контроллером.
Масштабирование линии сетки тоже привязывается к ближайшей вершине в пределах восьми
пикселей. Панорамирование и зум не меняются во время жеста левой кнопкой.

Поведение сверено с UVOffsetTool, UVViewHelper и UVScaleTool TrenchBroom.

## Что проверить

- Перемещение текстуры во всех направлениях: она должна следовать за курсором.
- Разные уровни зума, масштабы текстуры, повёрнутые и зеркальные UV.
- Прилипание границы текстуры к краям грани без точного наведения.
- Выход из зоны привязки и возвращение без накопления ошибки.
- Нажатие и отпускание Ctrl во время жеста.
- Отпускание кнопки на ходу, Undo/Redo и отмена через Escape.
- Масштабирование линией сетки, вращение кольцом и сохранение MAP.

Автоматические проверки описаны в английской версии `uv-dragging.md`.

При сильном увеличении перемещение вне зоны привязки использует дробные шаги
размером примерно в один экранный пиксель (не больше одного текселя).
Для точного размещения рядом с целью привязки удерживайте Ctrl.
