# Alpha 50: Subdivision, конвертация брашей и управление генераторами

Subdivision теперь ориентирует разрезы по выбранной грани, учитывает поворот мировой сетки и умеет выбирать опорную грань для текстурной сетки без отдельного выделения грани. Делится весь объём браша; отдельная поверхностная оболочка не создаётся.

**Edit → Convert Triangulated Brushes** перестраивает выпуклые браши с объединением компланарных граней. Отдельные браши остаются отдельными; выделенная закрытая группа или брашевая энтити превращается в один выпуклый объём внутри того же контейнера. Группы с пустотами или раздельными частями отклоняются без изменения карты. Вся операция — один Undo/Redo.

Окна Terrain generator, Bevel, Fracture, Perforate, Inset, Subdivision и Rock получили **Default**, **Undo settings** и **Redo settings**, до 128 шагов на инструмент. Пока окно открыто, Ctrl+Z и Ctrl+Shift+Z меняют настройки. Закройте его для отмены изменения самой карты. В текстовых полях сохраняется обычная отмена текста. Cancel, крестик и Escape вне ввода отменяют предпросмотр.

Rock создаёт отдельную группу на каждый исходный браш. Каждая группа получает собственную модель и геометрию. Для браша внутри игровой энтити группировку нужно отключить: перенос в редакторскую группу потерял бы поведение энтити, поэтому запрос отклоняется.

## Что проверить

1. Subdivision по целому брашу, вертикальной и наклонной грани; сохранение объёма и UV.
2. Разбиение по повёрнутой сетке и текстурным ячейкам с масштабом/смещением UV, включая режим без выделенной грани.
3. Конвертацию отдельных брашей и закрытой группы смежных выпуклых частей; Undo/Redo, сохранение и повторное открытие.
4. Отказ конвертации группы с пустотами: исходные части должны остаться нетронутыми.
5. Два исходных браша → Rock с группировкой → две независимые группы; отмену операции.
6. Во всех генераторах — историю настроек, Default, предпросмотр, Apply и отмену. После закрытия окна — Undo/Redo документа.
7. Эти же сценарии на Windows и Linux, включая небольшое окно Spawn Master.

Подробности и ограничения — в [английской документации](alpha50.md). Полный перенос ещё продолжается; [список паритета](reyond-parity.md) содержит оставшиеся пункты. Неиспользуемые функции поверхностного разбиения и сглаживания в исходниках Subdivision не считаются доступными функциями интерфейса.
