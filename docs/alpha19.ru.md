# Alpha.19 — завершение базовых функций и исправления больших карт

[English](alpha19.md) · [Что проверить](checks-alpha19.ru.md)

Релиз завершает оставшуюся базовую работу в пределах фаз 0–15. Интерфейс остаётся на Dear ImGui. Связанные группы, создание/редактирование патчей, Sweep, UV-редактор и интеграция компиляции/запуска в этот релиз не входят.

## Карты и отображение

Границы контейнеров теперь рассчитываются общим проходом и кешируются. Инспектор тоже больше не обходит все браши заново для каждой сущности. Это исправляет превышение лимита выполнения QuakeC при открытии `hotel02.map`.

Геометрия невыделенных групп и брашевых сущностей явно передаётся в рендер. Её видимость больше не зависит от подсветки выделения или флага отображения моделей точечных сущностей. Скрытие слоёв, фильтры классов, замещение геометрии предпросмотром и прозрачность специальных материалов сохраняются.

При сохранении MAP движок строит устойчиво разнесённые точки из уравнения плоскости. Ранее первые три вершины тонкой грани могли оказаться почти на одной прямой и давать изменение формы после загрузки. Оси текстур и метаданные граней сохраняются прежним способом.

`hotel02.map` проверялась только в одноразовых тестовых установках; контрольная сумма исходника не изменилась. Карта пользователя не входит в репозиторий и архив. Регрессионная карта тонких фасок создана отдельно.

## Инспектор сущностей

- Один клик выделяет ячейку, повторный клик или F2 включает редактирование.
- Стрелки перемещают выделение; Tab/Shift+Tab идут по ячейкам; Enter — вниз по столбцу. Выход из ячейки фиксирует ввод, Escape отменяет текущую правку.
- Ctrl+Enter или **+ New property** добавляет пустое свойство и сразу редактирует его имя.
- Ctrl-клик выбирает несколько строк, Shift-клик — диапазон, Ctrl+A — все показанные строки. **− Remove** и Delete удаляют выбранные свойства одним Undo, не удаляя объекты сцены.
- Ключ `classname` защищён от удаления/переименования; класс меняется редактированием значения. Внутренние ссылки на модели брашевых сущностей защищены.
- Фактические свойства идут первыми, значения по умолчанию — ниже курсивом, если системный курсивный шрифт доступен. Отсутствующие у части выделения свойства приглушены. Смешанные значения показываются пустыми и не затираются простым входом/выходом из ячейки.
- Smart-редактор под таблицей следует выбранному свойству: флаги с промежуточным состоянием, варианты из определения или цвет. Цвет можно хранить в 0–1 или 0–255; рядом показаны цвета из свойств `color`/`_color` карты.

Определения моделей теперь передают skin, frame и scale. Для skin/frame поддержаны числовые значения и имена свойств. Scale принимает число, вектор или список свойств, например `modelscale, modelscale_vec`; используется последнее непустое. Атрибуты ENT и FGD, включая наследование, сохраняют эти параметры. Это ограниченный формат описания, а не произвольный язык скриптов. Плитки браузера показывают цветной bbox, как разрешает спека; модели в сцене рисует движок.

## Геометрия и организация

UV Lock при редактировании вершин/рёбер/граней сохраняет координаты текстуры соответствующих исходных вершин, в том числе после триангуляции. У ручки показываются координаты, при перетаскивании — жёлтые направляющие. Контуры рёбер/граней видны до выбора ручек. Коллинеарные точки Brush Tool показывают весь отрезок между крайними точками.

Меню создания сущностей и фильтры сгруппированы по префиксам классов. Для видимости классов, создания точечных классов и девяти фильтров тегов доступны назначаемые действия. Создание группы требует выхода из модального инструмента.

Слои можно выбирать Ctrl-кликом и удалять вместе с переносом объектов в Default Layer. В контекстном меню есть Hide, Lock, Omit from export. Перестановка и массовые операции со слоями отменяются одним Undo.

## Ограничения

Лимит браша — 64 плоскости; превышающие его настройки фигур отклоняются без изменения карты. Спека разрешает оставить нативное ускорение отдельным [предложением](native-geometry-proposal.ru.md). Данные существующих патчей сохраняются и отображаются, но инструментов их редактирования нет. Пиксельная идентичность другому редактору и произвольные выражения в определениях не заявляются.

Автоматические проверки перечислены в [TESTING.md](../TESTING.md), полный ручной список — [здесь](checks-alpha19.ru.md).

Выделение на больших картах больше не обходит весь документ для каждого отдельного объекта. Проверены Select All и Invert на всех 2396 брашах и патчах тестовой карты.
