# Сетка и привязка — 0.5.0-alpha.5

[English](task-0.5.md)

Добавлены размеры сетки **0,125–256** с шагом вдвое. Выбор доступен на панели, в инспекторе Grid и в **View → Grid**.

| Управление | Действие |
|---|---|
| 1–9 над сценой | Размеры 1–256 |
| +, =, плюс цифрового блока | Увеличить, максимум 256 |
| −, минус цифрового блока | Уменьшить, минимум 0,125 |
| 0 | Показать/скрыть сетку |
| Alt+0 | Включить/отключить привязку |
| Ctrl+Alt+колесо | Вниз — крупнее, вверх — мельче |
| Обычное колесо в прежнем режиме | Вверх — крупнее, вниз — мельче |

Прежнее управление обычным колесом сохранено по умолчанию. Чтобы требовать Ctrl+Alt, отключите **File → Preferences → Plain wheel changes grid (legacy)**. **Invert grid wheel** меняет направление. Над панелями колесо прокручивает интерфейс.

**Snap to grid** позволяет отключить округление координат при создании, перемещении и расстановке Clip-точек. Тогда перемещение мышью становится плавным. Высота нового браша по умолчанию остаётся равной выбранному шагу сетки.

**Show grid** управляет сеткой поверх граней и плоскостью построения. **Grid opacity** задаёт прозрачность. Рисунок самой текстуры, в том числе клетчатой стартовой текстуры, эти настройки не меняют.

Слишком частые линии отображаются с более крупным шагом: ориентир — минимум четыре пикселя в проекции центра грани. Шаг фактической привязки при этом не меняется. Полная фоновая сетка ортографических видов с основными линиями остаётся задачей 1.2.

**Plane Z** — сохранённая особенность FTEBroom: высота XY-плоскости построения, если луч курсора не попал в геометрию. Clip на наклонной грани привязывает две координаты, а третью вычисляет по плоскости грани.

Добавлен общий модуль привязки, включая вычисление расстояния до попадания вершины на сетку для будущего Extrude. Сам инструмент Extrude на этом этапе не добавляется.

Автотесты проверяют клавиши, границы диапазона, дробные шаги, режимы колеса, защиту текстового ввода, наклонную плоскость с точностью 0,001, создание браша 0,125, свободное перемещение мышью и побитовое восстановление MAP через Undo.

Проверьте размеры 1–9 и 0,125, плавное перемещение после Alt+0, показ и прозрачность сетки, Ctrl+Alt+колесо после отключения прежнего режима и Clip на наклонной грани.
