# FTEBroom alpha.37 — первый запуск, профили и Linux

[Руководство с картинками](manual.ru.md) · [English](alpha37.md)

Оконный запуск Windows возвращён. Угол сетки целочисленный; прежние дробные значения
округляются. На новой установке мастер предлагает язык, профиль и ресурсы. Необязательные
для маппинга пути отмечены; в новых настройках нет персональных путей разработчика.

Профиль переименован в **FTE Custom game**, старые заголовки MAP совместимы.
**FTE Engine terrain** создаётся только в нём — запрет действует и на команду создания.
Отдельный генератор рельефа из брашей/патчей остаётся доступен для поддерживаемой геометрии.

После успешного **Build** открывается BSP во вьюпорте. Мод запускается только при явном
включении опции; прежнее неявное включение сбрасывается. Для обычной сборки Custom-профиля
необязателен настроенный runtime-мод. Файловый менеджер показывает два корня: **Mod files**
и **Map sources / authoring assets**. Переход к исходникам не меняет игровой мод.

Добавлены иллюстрированные руководства на английском и русском и первая нативная
Linux x86-64 сборка с Q3Map2 и компиляторами Quake 1. Linux требует Ubuntu 24.04/glibc 2.39+
и указанные [зависимости](linux.md). Встраивание окна мода, внешние desktop drag-and-drop,
автообновление и установщик LibreQuake пока остаются Windows-функциями. В Linux для WAD
есть поле пути, FFmpeg устанавливается системно, мод запускается отдельно через Run.

## Полный список проверок

1. Чистая установка Windows: окно с рамкой, сначала язык, затем профиль и ресурсы.
   Проверь Back/Next, все профили, пустые optional-поля, неправильный путь и исправление.
2. Повторный запуск без повторного мастера. При обновлении сохраняются пути, WAD,
   язык, раскладка и список последних карт.
3. Сетка: 1°, 37°, -45°, ввод числа через Ctrl-клик по ползунку, создание/перемещение,
   смена видов, перезапуск и Reset. Дробных углов быть не должно.
4. Старые карты пользовательского профиля открываются как FTE Custom game.
   Смена профиля корректно обрабатывает Save / Don't Save / Cancel.
5. В Quake 1/3 нельзя создать FTE Engine terrain из меню или командой. В Custom:
   создание на копии карты, Undo/Redo, мазок, выход из инструмента, сохранение/открытие.
6. Два корня менеджера: мод/исходники, вложенные папки и PAK, открытие MAP,
   Copy/Paste/Rename на тестовых файлах. После перехода к исходникам Preview mod
   по-прежнему использует папку мода.
7. Build во всех профилях открывает готовый BSP, а не мод. Возврат в MAP сохраняет
   геометрию, выделение и историю. В Windows отдельно проверь явное включение
   Open mod preview after Build и сохранение этого выбора.
8. Сборка Custom без runtime-мода: достаточно ресурсов и компилятора. Проверь
   BSP-only, все стадии, LIGHT-only для неизменённой карты, Stop и ошибочный компилятор.
9. Linux: зависимости, запуск, мастер, Open/Save, создание/Clip/Undo/Redo, сборка
   Quake 1/3 и просмотр BSP. Звук проверяй на копии с установленным FFmpeg.
10. Большая карта: 3D/2D, FPS, материалы, модели, патчи, ввод текста и сообщения
    консоли. Качество отрисовки в этой версии не снижалось.
11. Руководство из README: изображения и ссылки, инструкции по профилям, WAD,
    файловому менеджеру, terrain, Bevel, звуку и сборке.
